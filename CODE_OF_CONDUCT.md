# Code of conduct

TurnStage contributors are expected to keep project spaces professional,
welcoming, and focused on the work.

- Treat people with respect regardless of background, identity, experience, or
  point of view.
- Give specific, constructive feedback about ideas and code rather than people.
- Do not harass, threaten, discriminate, publish private information, or use
  sexualized or demeaning language.
- Protect credentials, customer data, and unreleased vulnerability details.

Project maintainers may edit or remove contributions and restrict
participation when behavior harms contributors or the project. Report conduct
concerns privately through the repository owner's GitHub profile. Do not use a
public issue when doing so would expose personal or sensitive information.
