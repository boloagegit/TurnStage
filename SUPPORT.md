# Support

TurnStage is a public-preview project maintained through GitHub.

## Before opening an issue

1. Install the latest TurnStage release and a supported VS Code version.
2. Reproduce the problem with the bundled localhost mock server when possible.
3. Run Connection Doctor for HTTP, streaming, proxy, timeout, and mapping
   problems.
4. Review the TurnStage Output channel. Do not paste secrets, headers, prompts,
   transcripts, URLs with query values, payloads, or private endpoint names.
5. Export a sanitized evidence report when the issue concerns a test result.

Use [GitHub Issues](https://github.com/boloagegit/TurnStage/issues) for bugs and
feature requests. Use the private process in [`SECURITY.md`](SECURITY.md) for
security or privacy concerns.

TurnStage does not provide guaranteed response times, production support, or
model-safety certification during the public preview.
