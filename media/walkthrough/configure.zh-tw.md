## 設定完整流程

依序完成 Profile Configuration 的各區段：

1. **一般** — 識別資訊與 environment。
2. **開場與流程** — 開場訊息、variants、停止與錯誤復原。
3. **請求** — endpoint、headers、body、逾時、重試與 redirect。
4. **串流與 Mapping** — 將後端事件轉成聊天事件。
5. **Chat UI** — 預覽版面與互動行為。
6. **歷史與錯誤**、**安全性** — 保存策略與 allowlist。

傳送接近正式環境的流量前，先確認已遮蔽敏感值的 request preview。
